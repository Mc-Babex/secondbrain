# SecondBrain

SecondBrain ist eine persönliche PWA (Progressive Web App) zum **Erfassen, Sortieren und Einplanen**:
Gedanken per Text oder Sprache festhalten, in Ablagen einordnen und als Termine in den eigenen
Google-Kalender legen. Die Daten liegen in einem privaten Repo der jeweiligen Nutzerin bzw. des Nutzers.

**Testphase – Teilnahme nur auf Einladung.**
